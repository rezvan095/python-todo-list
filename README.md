# Консольный ToDo-лист на Python

Мой первый учебный проект — менеджер задач для командной строки. 

## Функционал:
- Добавление задач
- Просмотр списка (с отметкой выполненных)
- Отметка задач как выполненных
- Удаление задач
- Сохранение данных в файл JSON (задачи не пропадают после перезапуска)

## Как запустить:
1. Установите Python 3.
2. Скачайте проект.
3. В терминале выполните:
   ```bash
   python MVP.py
